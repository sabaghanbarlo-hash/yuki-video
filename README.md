# Yuki Lab

A code-drawn YouTube animation studio for **science explainers, fascinating facts and "what if" scenarios**.
Paste a script → the lab splits it into scenes, chooses places, characters and camera moves from what the words say,
records the narration (the same matched voice as Yuki Studio), adds subtitles, transitions and sound, and renders an **MP4**.

Everything on screen is generated by code in `lab/` (no stock footage, no copied assets, no paid APIs):

| Look | What it is |
|---|---|
| **Flat explainer** | Kurzgesagt-inspired layered backdrops (space, ocean, cells, cities ...), glowing planets, diagrams, number counters, timelines, arrows |
| **Blocky 3D world** | Minecraft-style voxel worlds (plains, desert, snow, ocean, undersea, volcano, city, cave, space, sky islands), blocky people and animals, meteors, rockets, eruptions - drawn by a small software 3D engine |
| **Simple characters** | Infographics-Show-style bean-bodied cartoon people (astronaut, scientist, diver ...) that walk, point, panic, cheer, with 13 cartoon locations |

**The video is not a fixed template.** `lab/director.py` reads every scene and every shot: what it is about (topic), the mood, whether it
has numbers, a comparison, a process, a list, a timeline, a question or a "what if" - then picks the look, place, time of day,
camera move, who is on screen, what they do and what pops up. Different scripts (and different scenes of one script) look different;
`--seed` re-arranges the same script.

## Use it

**Web page (easiest):** open the Yuki Lab page (GitHub Pages of the `yuki-studio` repo), paste a script, press *Preview scenes* (≈1 min,
one still per scene) and *Make the video*. The MP4 appears under the run's *Artifacts → video*; it can also be uploaded to YouTube.

**GitHub Actions:** Actions → *Make video* → Run workflow (script path, look, seed, voice, optional uploaded narration).

**Locally** (Python 3.10+, ffmpeg):

    pip install -r requirements.txt
    python generate.py scripts/sample.txt                       # Kokoro voice (pip install torch kokoro soundfile; see workflow)
    python generate.py scripts/sample.txt --tts edge            # Microsoft voices, needs internet
    python generate.py scripts/sample.txt --tts babble          # offline test sound (not speech) - tests the whole pipeline
    python generate.py scripts/sample.txt --audio my-voice.mp3  # your own narration (cut into sentences at your pauses)
    python generate.py scripts/sample.txt --preview out/prev    # scene stills + plan.json, no voice
    python generate.py scripts/sample.txt --style voxel --seed 3
    python make_thumbnail.py scripts/sample.txt --out out/thumb.jpg

Rendering speed: about 8 frames/s per core; a 3-minute video takes roughly 10-15 minutes on a 2-core runner.

## Script format

    # Video title                      <- title card
    ## Scene heading                   <- starts a scene (a line with only --- does the same)
    Plain paragraphs are narrated.
    [style: voxel | env: ocean | time: night | camera: ...]   <- optional cues for the scene (own line)
    Inline cues sit where they should happen: [sfx: explosion] [pause: 1.2]

Without any `##` dividers the script is cut automatically at topic changes and at a natural scene length.
Cue keys: `style` (flat/voxel/toon), `env` (space, ocean, underwater, volcano, city, cave, desert, snow, plains, lab, forest ...),
`time` (day/dusk/night/storm), `palette`, `mood`, `transition` (fade/wipe_l/wipe_r/slide/push/iris/zoom/flash), `show` (a thing to draw), `seed`, `sfx`, `pause`.

## Voice

* `voicestudio`: [Voice Studio](https://github.com/debpalash/VoiceStudio) (OmniVoice engine, free, runs on the CPU). It speaks in the voice of `voice/ref.*` (put the exact words said in `voice/ref.txt` for best results, otherwise Whisper reads them). Higher quality than Kokoro but slow: about 4 minutes per sentence on a GitHub runner, so a 40-sentence script needs roughly 3 hours. Note: no subtitles are burned into the video.
* `kokoro` (default): free open-source voice picked to be closest to your sample (`voice/match.json`, re-run *Match my voice* after replacing `voice/ref.*`),
  with the storyteller delivery layer (`lab/expressive.py`).
* `clone`: your own voice via Chatterbox (`voice/ref.*`), slow on CPU.
* `edge`: Microsoft voices (free, sometimes blocked on shared runners).
* uploaded audio: one recording of the whole script; sentences are found at your pauses.

## Layout

    generate.py            command line         lab/pipeline.py   plan -> voice -> timeline -> sound -> frames -> MP4
    lab/script.py          script parser         lab/director.py   the "brain": styles, places, shots, actors, camera, sfx
    lab/knowledge.py       topics/moods/things   lab/compose.py    frames, transitions, captions, title/outro cards
    lab/flat_env.py entities.py   flat backdrops + 60 drawn things          lab/stage2d.py   flat + character scenes
    lab/toon.py toon_envs.py      cartoon people, animals, places            lab/stage3d.py   blocky 3D scenes
    lab/voxel.py           3D engine, worlds, people, props                  lab/voice.py expressive.py sfx.py   narration + sound
    publish_youtube.py     YouTube upload        .github/workflows generate.yml preview.yml match-voice.yml voice-test.yml

Adding things is data: a new topic/thing/mood is a line in `lab/knowledge.py`; a new voxel prop is a function in `lab/voxel.py`.

## YouTube upload

Repository secrets `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` (unchanged from Yuki Studio). The YouTube refresh token for an
unverified app lasts about 7 days; renew it when the upload step reports `invalid_grant`.
