# Yuki Toon (new cartoon look)

Script in, cartoon video out: the new hand-drawn Yuki, her cloned voice (Voice Studio), automatic upload to the Yuki's Mind Lab channel (always private, like the rest of this repo).
Started from the Yuki Toon Studio website (https://sabaghanbarlo-hash.github.io/yuki-toon/) or by hand: Actions -> "Toon video" -> Run workflow.

The voice work is split over up to 20 GitHub machines at once, so a long script does not hit the 6 hour limit.
Everything here is separate from the older system (generate.py, lab/): nothing there was changed.
